# Frame V17 — CNC files

8" × 8" frame made from **2 identical halves** of 3/4" cherry, glued groove face to groove face (1-1/2" total).

| File | What it is |
|---|---|
| `V17_half.step` | **Solid model of one half (cut ×2) — best file for CAM.** Bevel face up, groove face down |
| `V17_assembly.step` | Both halves glued, as two solid bodies |
| `Frame_Parts_V17.pdf` | Dimensioned drawing (inches) |
| `V17_Half_Actual_Size.pdf` | 1:1 print of the front and back faces (print at 100%) |
| `V17_half.dxf` | 2D geometry in inches: both faces + 1:1 profile, on separate layers |
| `v17_frame_half.stl` | 3D model of one half (cut ×2), inches |
| `v17_frame_assembly.stl` | Both halves glued, for reference, inches |

## Key dimensions (each half)

- Stock: 8.000 × 8.000 × 0.750
- Opening: Ø6.125 through
- Front bevel: 35° from face, 0.625 run × 0.4375 deep, outer edge Ø7.375
- Straight wall below bevel: 0.3125
- Margin to edge (at side midpoints): 0.3125
- Back groove: Ø6.875 ID / Ø7.250 OD (0.1875 wide) × 0.375 deep
- Min. wood between groove and bevel: 0.200

STEP files carry units (saved in mm, CAM converts automatically). STL files have no units; import as **inches**.
