# Frame V17

Website for the V17 knit frame: installation studies, CNC model viewer, drawings and CNC files.

- `index.html`: landing page
- `studies/`: 3D installation and lighting studies (self-contained HTML)
- `step-viewer/`: viewer for the STEP solids
- `cnc/`: STEP, DXF, STL and PDF files for the CNC shop (see `cnc/README.md`)

Everything is static and self-contained (no build step, no external scripts), about 5 MB total.
